BasePerso Sync GoogleCalendar

BasePerso Sync GoogleCalendar est une application personnelle permettant de synchroniser Google Calendar avec une base Microsoft Access.

L'application permet notamment :

  • d'importer des evenements Google Calendar dans la base personnelle ;
  • de synchroniser les modifications effectuees dans Access vers Google Calendar ;
  • de gerer les rendez-vous, taches et evenements personnels.

Cette application est reservee a un usage prive par les utilisateurs autorises.
